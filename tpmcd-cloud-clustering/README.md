# TPMCD: A method to optimizing cost and throughput for clustering tasks and hybrid containers in the cloud data center

**Year:** 2025  
**Journal:** Journal of Network and Computer Applications  
**Publisher:** Elsevier  
**DOI/Link:** [Access via ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S1084804525000293)

---

## Abstract
The regulatory of task classification or clustering and hybrid containers in cloud data centers has a lower overhead of cost compared to virtual machines, also it has a direct impact on the load balance, accessibility of virtual machines, and increase of efficiency. In the proposed method, merging the index parameters of response time, execution accuracy and their sensitivity rate have been used. In **TPMCD** (ThroughPut and cost optimizing Method for Clustering tasks and hybrid containers in the cloud Data center), efficiency and energy consumption decrease synchronously against dynamic workloads. TPMCD method have optimized time and cost by decreasing redundancy, showing improvements in cost (7%), throughput (4%), and real execution time (9.5%).

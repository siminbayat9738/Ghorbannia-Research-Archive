
# HDECO: A method for Decreasing energy and cost by using virtual machine migration by considering hybrid parameters

### Abstract
Energy and cost are important issues in cloud computing, which led to increased power supply consumption and more carbon dioxide production. In this paper, cost and energy have been studied with other migration parameters like migration time and downtime. The HDECO method is proposed for virtual machine migration to optimize these hybrid parameters...
